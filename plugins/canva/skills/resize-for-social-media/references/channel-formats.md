## Default channel set

Use when the user asks for each channel, all channels, every platform, platform-ready variants, or channel-ready variants and does not name placements, ratios, or pixel dimensions. This is one preferred placement per platform named in the skill description. Exact duplicate canvases are already merged.

LinkedIn landscape (1200 × 627), X landscape (1200 × 628), and the Facebook link image (1200 × 630) are a few pixels apart. On this generic request, create 1200 × 627 once and label it for all three. Create 1200 × 628 or 1200 × 630 only when the user names that placement.
